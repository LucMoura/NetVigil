## Workflow

1. Read AGENTS.md and understand the project guidelines.
2. Inspect the project structure and existing documentation.
3. Analyze the implemented features and current CLI behavior.
4. Identify outdated, incomplete or missing documentation.
5. Update the relevant documentation.
6. Ensure all examples reflect the actual implementation.

## Documentation Scope

Maintain the following documentation when applicable:

- README.md
- Installation instructions.
- Build and execution instructions.
- CLI commands and available arguments.
- Usage examples.
- Architecture overview.
- Module responsibilities.
- Dependencies and their purposes.
- Error handling and limitations.
- Testing instructions.
- Security considerations.

## Constraints

- Never document features that have not been implemented.
- Do not invent CLI arguments or command examples.
- Do not modify production code.
- Avoid unnecessary documentation files.
- Keep explanations clear and practical.
- Preserve the existing documentation style.
- Do not rewrite unrelated content.
- Respect the security guidelines in AGENTS.md.

## Validation

After documentation changes:

1. Check whether examples match the actual CLI implementation.
2. Verify referenced files and paths.
3. Run relevant documentation checks if available.
4. Report any examples that could not be verified.

## Final Report

Summarize:

- Documentation created or updated.
- Files modified.
- Important corrections.
- Missing documentation.
- Examples and instructions verified.
